# 🐍 Python Tkinter Mini Projects

This repository contains a collection of beginner-friendly **Python projects using Tkinter**. These projects helped me practice Python programming, GUI development, functions, conditions, loops, and event handling.

## 📂 Projects Included

### 🏧 1. ATM System
**File:** `ATM System.ipynb`

A simple ATM System that simulates basic ATM operations.

**Features:**
- Check Balance
- Deposit Money
- Withdraw Money
- Simple GUI interface

### 🧮 2. Calculator
**File:** `Calculator.ipynb`

A GUI-based calculator created using Python Tkinter.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Clear option

### 🎯 3. Guess Game
**File:** `Guessgame.ipynb`

A simple number guessing game where the user tries to guess the correct number.

**Features:**
- User input
- Number comparison
- Correct/Wrong guess messages
- Interactive GUI

### 🔢 4. Prime Number Checker
**File:** `Primechecker.ipynb`

A simple application that checks whether the entered number is prime or not.

**Features:**
- Enter a number
- Check Prime/Not Prime
- Display result using Tkinter

## ▶️ How to Run

1. Install Python on your system.
2. Install and open Jupyter Notebook or JupyterLab.
3. Download or clone this repository.
4. Open the required `.ipynb` file.
5. Run all cells.
6. The Tkinter application window will open.

## 🎯 Purpose

The main purpose of these mini projects is to practice **Python fundamentals and GUI development using Tkinter**.

These projects are suitable for beginners who are learning how Python can be used to create interactive desktop applications.
